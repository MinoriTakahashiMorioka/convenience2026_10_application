# 総合便利アプリ（Web版）

HTML / CSS / JavaScript だけで動く Web アプリです。
ビルドツールやインストールは不要で、ブラウザ版 VSCode（vscode.dev）でそのまま編集できます。

## 動かし方

### A. ブラウザ版 VSCode で編集して確認する
1. zip を展開する
2. Chrome か Edge で https://vscode.dev を開き、「フォルダーを開く」で展開した `benri-app` フォルダを選ぶ
3. 左の拡張機能から **Live Preview**（Microsoft製）を入れる
4. `index.html` を開いて、右上のプレビューボタン（または右クリック →「Show Preview」）

> `index.html` をダブルクリックして直接開くと動きません。
> JavaScript をモジュールに分けているため、http で配信する必要があります（Live Preview がそれをやってくれます）。

### B. iPhone で使う（GitHub Pages で公開）
1. GitHub に新しいリポジトリを作り、フォルダの中身をアップロード
2. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
3. 数分後に出る URL を iPhone の Safari で開く
4. 共有ボタン →「ホーム画面に追加」でアプリのように使える

GitHub のリポジトリ画面で `.` キーを押すと、そのままブラウザ版 VSCode（github.dev）で編集もできます。

### ログイン・新規登録
- ログイン画面の「新規登録」からアカウントを作れます（登録するとそのままログイン）
- お試し用: `demo` / `password`、`admin` / `admin123`

## 設計のポイント

### 画面の流れ
```
起動 → ログイン状態を復元
        ├─ 未ログイン → #/login
        └─ ログイン済み → #/hub → カードを押す → #/app/calendar など
```
- ログイン・ログアウト時は履歴を「置き換え」るので、戻るボタンでログイン画面に戻りません
- 各画面は「後片付け関数」を返せます。画面を離れるときに自動で呼ばれるので、
  タイマーを止め忘れる心配がありません（ステップ3のポモドーロで使います）

### 機能は「名刺」を出すだけ
各機能は `defineFeature()` で次の情報を出します。ハブはこれを並べるだけです。

| 項目 | 内容 |
|---|---|
| `id` | URL にも使うID（`calendar` → `#/app/calendar`） |
| `title` / `subtitle` | カードの表示名・説明 |
| `icon` / `color` | カードのアイコンと色 |
| `keywords` | 検索用の別名 |
| `summary(ctx)` | カード下部の一言（「今日の予定 2件」など） |
| `mount(root, ctx)` | 画面を描画する本体 |

### データの持ち方
- 保存は全部 `storage.js` 経由（将来クラウド保存にするときはここだけ差し替え）
- 機能ごと・ユーザーごとに保存場所が分かれる
  `benri:v1:u:demo:calendar:events` のように、demo さんのカレンダーと admin さんのカレンダーは混ざらない
- 日付は `'2026-10-13'`、時間は `'14:30'` という文字列で保存（Date 型の時差ずれ事故を防ぐ）
- 木構造の Todo は「親のID（parentId）」を持つ平らな配列で保存（どの階層でも id だけで更新・削除できる）

## カレンダー機能（ステップ2）

| できること | 操作 |
|---|---|
| 予定を追加 | 右下の「予定を追加」→ タイトル・日付・時間・ラベル・メモ |
| 時間をすばやく入力 | 9:00 / 12:00 / 15:00 / 18:00 / 20:00 のボタン、または「終日」 |
| 予定を編集・削除 | 一覧の予定をタップ |
| 月を移動 | ‹ › ボタン、またはカレンダーを左右にスワイプ |
| ラベルで絞り込み | 月の下のチップ（すべて・仕事・…） |
| カスタムラベル | 右上の「ラベル」、または予定の入力中に「ラベルを追加・編集」 |

- ラベルは「仕事・プライベート・勉強・重要」が標準。標準は名前と色を変えられるが削除はできない
- カスタムラベルを削除すると、そのラベルの予定は消えずに「ラベルなし」になる
- 日曜・祝日は赤、土曜は青。祝日（振替休日・国民の休日を含む）は 2016〜2099年に対応。法律が変わったら `dates.js` を更新
- スマホ幅ではマスに色の点、PC幅では予定のタイトルを表示
- demo アカウントにだけ、初回にサンプル予定が入る（`index.js` の `seedDemoEvents`）

## 勉強機能（ステップ3）

上のタブで「Todo / タイマー / 記録」を切り替えます（最後に開いたタブを覚えています）。

### 木構造 Todo
| できること | 操作 |
|---|---|
| 大きなタスクを追加 | 上の入力欄 →「追加」 |
| 子タスクを追加 | 行の「＋」→ 入力して Enter（続けて何件でも入力できる。Esc で終了） |
| 開く・閉じる | 行の左の ▸ |
| 名前の変更・削除 | タスク名をタップ（子タスクがあれば一緒に削除されることを確認） |
| そのタスクの勉強を始める | タスク名をタップ →「タイマーで勉強する」 |

完了のルール：親をチェックすると子孫もすべて完了。子が全部完了すると親も自動で完了し、1つでも外すと親も未完了に戻ります。

### ポモドーロタイマー
- 5・15・25・45分のボタン、または「自由に入力」で1〜180分
- 集中が終わるとチャイム（対応端末は振動も）が鳴り、**自動で記録**される → 「5分休憩」「もう一度」「記録を見る」
- 「終了して記録」で途中で終えても、1分以上なら経過時間を記録
- 終わる時刻を保存しているので、別のタブ・ハブ画面に移ったり再読み込みしても続きから動く（作動中はタブとブラウザのタイトルに残り時間）
- 作動中は画面が暗くならないようにする（対応ブラウザのみ）。PC ではスペースキーでスタート／一時停止

### 勉強時間の記録
- 今日・直近7日・連続日数・累計
- 日ごとの棒グラフ（7日 / 30日）、内容別の合計
- 一覧から記録をタップで編集・削除、「記録を追加」で過去の分を手入力

## 日記機能

上の切り替えで「日 / 週 / 月 / お気に入り」。右上の「書く」でいつでも書けます（1日に1つ）。

### 書く・直す
- 日付（今日が自動で入る・選び直せる。まだ来ていない日は不可。すでに書いた日を選ぶと「その日の日記を開く」）
- 今日の評価 ♡1〜5（同じ♡をもう一度押すと「なし」）
- 日記の文章は **350文字まで**、反省と改善は **150文字まで**（残りの文字数を表示。上限以上は入力できない）
- ☆お気に入り登録（ページ右上の☆でもすぐ切り替えられる）
- 編集画面から削除

### 表示
- **日**：画面いっぱいに1日分（ノートの罫線つき）。**左端に前の記録日、右端に次の記録日**（PC は日付と書き出し、スマホは縦書きの日付）。スマホは左右スワイプ、PC は ← → キーでも移動。日付を選んで飛ぶ・「今日」もある
- **週**：カレンダーから週（1行）を選ぶ → 月〜日の7日分のカード。記録日数・♡の平均・☆の数
- **月**：年の中から月を選ぶ → ♡の濃さで気分が分かる「気分のカレンダー」と、その月の日記のカード（「記録のない日も表示」で全日）
- **お気に入り**：☆を付けた日記の一覧

## 体調ログ機能

上の切り替えで「記録 / カレンダー / グラフ」。

### 記録（1日1件・入れたそばから自動で保存）
- **睡眠**：寝た時刻と起きた時刻 → 睡眠時間を自動計算（日付をまたいでも OK）。眠りの深さ（ぐっすり・ふつう・浅い）
  - **ルーティンと連動**：ルーティンの「睡眠」の予定（就寝は前の日のパターン、起床はその日のパターン）が目安として出て、「予定どおりに入れる」でワンタップ入力。予定より何分長い・短いかも出る
- **体重**：kg（小数1けた）。前回の記録との差
- **気分**：朝・昼・夜それぞれ5段階の顔。2つ以上つけると「朝 😐 → 夜 😄」のように1日の変化が出る
- **体調**：朝・昼・夜それぞれ5段階＋気になること（頭痛・だるい・眠い など）
- **メモ**（200文字）、下に「この日のほかの記録」（予定・日記・エンタメ記録）

### カレンダー
月の表に、気分の顔・睡眠時間・体重を小さく表示（気分の色でマスがうっすら色づく）。症状がある日は右上に点。タップでその日の記録へ。月の平均睡眠・気分の平均・体重の変化も。

### グラフ（7日・30日・90日）
- 睡眠時間の棒グラフ（ルーティンの予定の点線つき）、平均の就寝・起床時刻
- 体重の折れ線グラフ（「目安の線を引く」で好きな体重に点線）
- 気分と体調の折れ線グラフ（1日の平均）、気になったことの回数
- 棒や点に指・マウスを乗せると、その日の値が出る

## エンタメ記録帳機能

読んだ本・観た映画・行った場所・その他（ドラマ・ライブ・ゲームなど）のレビューを、日記のように残せます。

- **本**：表紙の写真、タイトル、作者・著者、☆5段階、感想
- **映画**：写真、タイトル、☆5段階、感想（どこで観たか：映画館・配信 など も選べる）
- **場所**：写真、場所の名前、住所・エリア、☆5段階、感想
- **その他**：写真、タイトル、ジャンル、☆5段階、感想
- 写真は長い辺 520px の JPEG に小さくして保存（端末の容量を節約）。容量がいっぱいのときは知らせて保存しない
- 一覧は本棚のようなカード。種類のタブ・言葉で探す（タイトル・作者・感想）・並べ替え（新しい順・評価順 など）・☆で絞り込み。上に今年の記録数

### 日記との連携
- 記録の日付（読んだ日・観た日・行った日）と同じ日の日記のページに「この日のほかの記録」として出る。タップでその記録へ
- 記録の表示ページの下には「その日の日記」（なければ「この日の日記を書く」）
- 日記のページの「この日の本・映画・おでかけを記録」から、その日の日付で記録を書ける

## 機能どうしのつながり（日付）
`js/core/day-links.js` で、機能が「その日の記録」を出し合っています。
- **カレンダー**：選んだ日の下に「この日の記録」（日記・体調ログ・エンタメ記録帳・金銭出納帳）。記録のある日には機能の色の小さな横棒
- **日記**・**体調ログ**・**エンタメ記録帳**：それぞれのページの下に、同じ日のほかの記録
- 新しい機能でも、defineFeature に `dayInfo(ctx, date)` と `recordDates(ctx)` を書けば自動でつながります

## 金銭出納帳機能

上の切り替えで「追加入力 / 表示 / 削除」。右上の「？ 科目の説明」で勘定科目の説明（意味と例・検索つき）がいつでも見られます。

### 帳簿の並び
**年月日 | 内容 | 勘定科目 | 入金 | 出金 | 残高** の横1行（スマホでは1行が1枚のカード）。
- 必須は **内容だけ**。年月日・勘定科目・入金・出金はなくても可
- **残高は自動計算**（前の行の残高＋入金−出金）。途中の行を直す・消すと、それより下の残高も自動で直る
- いちばん上は「前期繰越（はじめの残高）」。「変更」で金額を入れられる（マイナスも可）
- 月が変わるところに区切りと、その月の入金・出金の合計

### 追加入力モード
- 画面の下に、帳簿と同じ列の入力行が固定。入金・出金を入れると右端の残高がその場で変わる
- 勘定科目を選ぶと、入金の科目なら入金欄、出金の科目なら出金欄へ自動で移動（反対側に入れた金額も移してくれる）
- Enter で追加。年月日はそのまま残るので同じ日の分を続けて書ける。追加直後は「取り消し」できる
- 帳簿の行をタップ → その行を入力行に読み込んで直す（「更新」「やめる」「この行を削除」）
- 日付が前後している行があると「日付順に並べ替え」が出る（日付のない行は直前の行と一緒に動く）

### 表示モード
- 大きく「現在の残高」、入金・出金・差引の合計
- **項目ごとに検索**：期間（今月・先月・今年・全期間 or 日付で指定）、内容（言葉）、勘定科目（「科目なし」も選べる）、入金の金額（下限〜上限）、出金の金額（下限〜上限）、区分（入金だけ / 出金だけ）。条件は組み合わせられて、合計も検索結果に合わせて変わる
- 内容で探した言葉は黄色で目立つ。「出金の内訳」の棒をタップするとその科目で絞り込み
- 「CSVで保存」で、いま表示している行を Excel で開けるファイルに保存

### 削除モード
- 行をタップして選ぶ（「すべて選択」「この月をすべて選択」もある）→ 下のバーで「削除」→ 確認 →「削除する」
- 消したあとも、お知らせの「元に戻す」で戻せる

## 一日のルーティン機能

上の日付バーで日付を切り替え（‹ ›・「今日」）。その下は **左に縦の予定表、右にパネル（Todo ／ 予定）** の1画面です。
左右はそれぞれの中でスクロールするので、予定表を動かしても右のパネルは見えたままです。

### 予定表
- 0〜24時の縦のタイムライン。今日は「今」の赤い線と「いま〇〇・あと〇分／次は〇〇」を表示し、開くと今の時刻まで自動でスクロール
- 予定は開始・終了・種類（睡眠・食事・勉強など9色）・メモ。名前から種類を自動で推測（「朝ごはん」→食事）。23:30〜6:30 のような日付をまたぐ予定もOK
- 「予定を追加」（または予定表の空いているところをタップ）→ 右のパネルが入力欄になり、入力中の予定が予定表に**点線の枠**でその場に表示される。時刻を変えると枠も動く
- 入力中に予定表をタップすると、開始時刻をそこに合わせられる（長さはそのまま）。ほかの予定と重なると「〇〇と重なっています」と表示
- 予定をタップすると右のパネルで編集・削除（編集中の予定は薄く表示）
- 時間つきの Todo（〇時まで）は、予定表のその時刻に小さな印で表示。タップすると右の Todo へ
- 重なった予定は横に並べて表示
- 種類ごとの合計時間（睡眠 7時間 など）を表示
- 空のパターンは「学生の平日」「社会人の平日」「のんびり休日」のひな形や、ほかのパターンのコピーから作れる

### パターンと使い分け
- 「平日」「休日」は標準、「テスト期間」「旅行の日」などの特殊日はいくつでも追加（コピーして作る・名前変更・複製・削除）
- どの日にどのパターンを使うか：日付の指定 ＞ 祝日 ＞ 曜日 の順に決まる
  - 曜日ごと（月〜日）に選べる。祝日は「休日」か「曜日どおり」を選べる
  - 日付バーのプルダウンで、その日だけパターンを変えられる
- チップで別のパターンを表示・編集できる（その日のパターンには「今日」の印）

### Todo（右のパネルの「Todo」タブ）
- 「朝（〜11時）」「昼（11〜17時）」「夜（17時〜）」「いつでも」に分けて表示。今の時間帯に「いま」の印
- 各時間帯の「＋」から追加（Enter で続けて入力）。「〇時まで」の時間を付けられ、過ぎると赤字で「過ぎています」
- 「毎日」の Todo は日ごとにチェックが外れた状態から始まる。「平日の日だけ」のようにパターンで絞り込める
- 「この日だけ」の Todo は、終わらなかったら次の日に「持ち越し」で表示

## 個人情報機能

上のタブで「履歴書 / 目標」を切り替えます。項目は `profile/index.js` の `SECTIONS` に足すだけで増やせます（職務経歴書など）。

### 履歴書
- JIS 規格の履歴書に近い用紙で表示（明朝体・罫線・「〇年〇月〇日現在」・写真欄・満年齢を自動計算）
- 年の表記を「西暦／和暦」で切り替え（令和・平成・昭和・大正。2019年4月→平成31、5月→令和元）
- 「編集」で入力：更新日（「今日にする」ボタン）、顔写真、氏名とふりがな、生年月日、郵便番号・現住所・ふりがな、電話・携帯
- 学歴・職歴（年・月・学歴/職歴・内容）、資格・免許（年・月・資格/免許・名称）は行を追加・削除。表示は「学歴→職歴」、それぞれ古い順に自動で並び、最後に「以上」
- 顔写真は縦横 3:4（360×480px）に自動で切り抜いて、この端末にだけ保存
- ブラウザの印刷（Ctrl+P）では用紙だけが印刷される

### 目標
- 「目標」タブと「完了済み」タブ
- 種類は「期限つき（〇年〇月〇日までに）」と「一生の目標（期限なし）」。期限つきは期限の近い順、一生の目標は追加した順に並ぶ
- 一覧の目標をタップすると詳細へ（`#/app/profile/goals/<ID>`。ブラウザの「戻る」も使える）
- 詳細画面
  - 達成率の横棒バー（ロードマップの完了数から自動 / スライダーで手入力）
  - 達成の条件メモ（「〇日までに〇割取れていれば合格の可能性が高い」など。自動保存）
  - ロードマップ：ステップ（やること・条件＋期日）を追加。丸をタップで完了、期日順に並び「今日」の位置に印
  - 「目標を達成した！」でクラッカーの演出 → 完了済みへ。「未完了に戻す」もできる
- 完了済み：▽を開くと 目標登録日・期限・完了日・かかった日数・期限の何日前に達成したか・ロードマップ・条件メモ

## 新しい機能を追加する手順（例: メモ）

1. `js/features/memo/index.js` を作る

```js
import { defineFeature } from '../../core/feature.js';

export default defineFeature({
  id: 'memo',
  title: 'メモ',
  subtitle: 'さっと書き留める',
  icon: 'book',          // icons.js にあるアイコン名
  color: '#D89A17',
  mount(root, ctx) {
    const memos = ctx.store.get('items', []);   // この機能・このユーザー専用の保存領域
    root.textContent = `メモ ${memos.length}件`;
  },
});
```

2. `js/core/registry.js` に追加

```js
import memo from '../features/memo/index.js';
export const FEATURES = [calendar, study, memo];
```

これだけでハブにカードが増え、`#/app/memo` で開けるようになります。

## アカウント設定・バックアップ

ホームの右上のアイコン →「アカウント設定・バックアップ」

- 表示名の変更、パスワードの変更（登録したアカウントのみ）
- **データのバックアップ**：「ファイルに書き出す」で JSON ファイルを保存、「ファイルから読み込む」で元に戻す（別の端末への引っ越しにも使える）
- すべてのデータを消す（アカウントは残す）／アカウントを削除（パスワードで確認）
- お試し用の demo アカウントは、データを消すと最初のサンプルの状態に戻る

## 新規登録のしくみ
| 項目 | ルール |
|---|---|
| ユーザーID | 半角英小文字・数字・`_` `-` で3〜20文字（全角や大文字は自動で直す）。入力中に「使えます／使われています」を表示 |
| 表示名 | 20文字まで。ホーム画面のあいさつに使う |
| パスワード | 8文字以上、IDと同じは不可。強さを3段階で表示し、確認欄と一致するかもチェック |

- パスワードはそのまま保存せず、ランダムなソルト付きの PBKDF2-SHA256（10万回）でハッシュ化した値だけを保存（`benri:v1:auth:accounts`）
- ハッシュ化にはブラウザの Web Crypto を使うため、https か localhost で開く必要があります（Live Preview・GitHub Pages ならOK）
- データはユーザーIDごとに分かれるので、新しいアカウントは空の状態から始まります

## 注意
- アカウントはこの端末のブラウザの中だけにあります。別の端末では同じIDでログインできません（端末をまたぐならサーバー側の認証が必要）
- パスワードを忘れたときの再設定はありません（端末内だけで完結しているため）
- データはその端末のブラウザに保存されます（別の端末とは共有されません）
